# Commerce Console

A team MCP gateway for WooCommerce, with a React dashboard, personal API keys, role-based tool access, and Gemini chat with explicit write confirmation.

**[Documentation](docs/index.md)** · [Installation](docs/getting-started.md) · [Architecture](docs/system-design.md) · [Verification](docs/verification.md)

## Stack

React and TypeScript · Python 3.12 and FastAPI · Official MCP SDK · PostgreSQL · WooCommerce · Kubernetes and Helm

## Run locally

Follow the [installation guide](docs/getting-started.md) for prerequisites, credentials, and bootstrap. The complete local deployment runs on Docker Desktop; no paid VPS is required. Gemini chat needs a provider key and available quota.

This is an independent Urumi AI engineering assignment. The application repository is private; reviewers need access. Scope, operational limits, security decisions, API reference, and test evidence are maintained in the documentation.
