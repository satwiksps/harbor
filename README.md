A team MCP gateway for WooCommerce, with a React dashboard, personal API keys, role-based tool access, and Gemini chat with explicit write confirmation.

## Stack

React and TypeScript · Python 3.12 and FastAPI · Official MCP SDK · PostgreSQL · WooCommerce · Kubernetes and Helm

## Run locally

Follow the [installation guide](https://useharbor.pages.dev/getting-started/) for prerequisites, credentials, and bootstrap. The complete local deployment runs on Docker Desktop; no paid VPS is required. Gemini chat needs a provider key and available quota.

The application repository is private; source access is required to run it. Scope, operational limits, security decisions, API reference, and test evidence are maintained in the documentation.
